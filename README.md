//Para começar um projeto com Expo, primeiro é necessário criar uma pasta onde os projetos serão armazenados. O comando mkdir é utilizado //para criar uma pasta. No caso, foi criada a pasta desenvolvimento dentro do disco C.
//mkdir C:\desenvolvimento
//Depois de criar a pasta, é importante entrar nela utilizando o comando cd. Essa parte é importante porque os próximos comandos serão //executados dentro dessa pasta.
//cd C:\desenvolvimento
//Depois disso, pode-se criar um novo projeto Expo utilizando o comando:
//npx create-expo-app@latest
//O terminal irá fazer algumas perguntas durante a criação do projeto. Primeiro, é necessário confirmar a instalação, escolhendo Yes. //Depois, deve-se informar o nome do aplicativo. Neste projeto, o nome utilizado foi fakeAPI.
//Em seguida, aparece a escolha da versão do SDK do Expo. Como será utilizado o Expo Go para executar o aplicativo no celular, foi //selecionada a opção For learning with Expo Go (SDK 54).
//Depois que o projeto for criado, é necessário entrar na pasta do projeto. Essa etapa é importante, pois comandos como npm install e npm //run start precisam ser executados dentro da pasta que contém o arquivo package.json.
//cd fakeAPI
//Depois, deve-se instalar as dependências do projeto utilizando:
//npm install
//Após a instalação, o projeto pode ser iniciado com:
//npm run start
//Esse comando inicia o Expo e gera um QR Code. Para abrir o aplicativo no celular através do Expo Go, o computador e o celular precisam //estar conectados à mesma rede Wi-Fi.
//Para abrir o projeto no Visual Studio Code, estando dentro da pasta do projeto, utiliza-se:
//code .
//O ponto representa a pasta atual. Portanto, code . significa abrir a pasta atual, que é a raiz do projeto, no VS Code.
//O comando Ctrl + C pode ser utilizado no terminal para interromper o processo que está sendo executado. Por exemplo, quando o npm run //start estiver rodando, pressionar Ctrl + C encerra o processo do Expo.
